01 / BUILD

기계 설계 · 제작

프레임과 구동부, 경기 과제에 필요한 메커니즘을 직접 설계하고 조립합니다.

02 / CODE

03 / TEST

반복 테스트

실제 경기 상황을 가정해 문제를 찾고, 구조와 코드를 계속 개선합니다.

04 / TEAM

팀으로 해결하기

기계, 코딩, 전략 역할이 서로 연결되어 한 대의 로봇을 완성합니다.

신입 부원에게

잘하는 학생보다,
직접 해보고 싶은 학생.

로봇이나 코딩을 처음 접해도 괜찮습니다. 만들고 고치고 다시 시도하는 과정에 관심이 있다면 동아리 활동을 통해 배울 수 있습니다.

활동 · 대회

만들고, 코딩하고,
경기에서 검증합니다.

실제 참가 대회와 시즌 일정이 정해지면 이 페이지의 텍스트만 바꿔도 됩니다. 아래 구조는 FTC와 같은 로봇 대회를 준비하는 일반적인 활동 흐름을 보여줍니다.

STEP 01

게임 분석

규칙과 과제를 확인하고 필요한 기능과 경기 전략을 정합니다.

STEP 02

설계

아이디어를 비교하고 로봇 구조와 메커니즘을 계획합니다.

STEP 03

제작

프레임과 부품을 조립해 실제 로봇 형태를 완성합니다.

STEP 04

프로그래밍

센서, 모터, 자율주행, 조종 코드를 구현합니다.

STEP 05

테스트 · 대회

반복 테스트와 개선을 거쳐 실제 경기에서 로봇을 운영합니다.
