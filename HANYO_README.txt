하뇨야! TC 홈페이지 글 수정은 이제 TXT 2개만 보면 돼.

============================================================
1. 한국어를 수정할 때
============================================================
HANYO_TEXT.txt 파일을 열어서 수정하면 돼.

예시:
[홈 메인 제목]
Think
Create
[강조]We are TC.[/강조]

대괄호 안 제목은 그대로 두고,
그 아래 내용만 바꾸면 실제 한국어 사이트에 반영돼.

============================================================
2. 영어를 수정할 때
============================================================
HANYO_TEXT_EN.txt 파일을 열어서 수정하면 돼.

한국어를 수정해도 영어가 자동 번역되지 않아.
영어 화면에 보여줄 문장은 HANYO_TEXT_EN.txt에 직접 적으면 돼.

============================================================
3. GitHub에서 수정하는 방법
============================================================
1) HANYO_TEXT.txt 또는 HANYO_TEXT_EN.txt를 연다.
2) 연필(Edit) 버튼을 누른다.
3) 원하는 문장만 수정한다.
4) Commit changes를 누른다.
5) GitHub Pages가 갱신되면 사이트에 적용된다.

중요:
- [홈 메인 제목], [소개 설명] 같은 대괄호 제목은 바꾸지 마.
- index.html이나 site-data.js는 글 수정 때문에 건드릴 필요 없어.
- 한국어: HANYO_TEXT.txt
- 영어: HANYO_TEXT_EN.txt
- 일본어 / 러시아어 / 힌디어 / 불가리아어는 기존 site-data.js 번역을 그대로 사용해.

============================================================
4. 글 꾸미기
============================================================
줄바꿈: 그냥 엔터
강조: [강조]내용[/강조] 또는 [highlight]content[/highlight]
굵게: [굵게]내용[/굵게] 또는 [bold]content[/bold]
밑줄: [밑줄]내용[/밑줄] 또는 [underline]content[/underline]
색상: [빨강]내용[/빨강] 또는 [red]content[/red]
직접 색 지정: [색=#6c63ff]내용[/색]

============================================================
5. 사진이나 지원 링크를 바꿀 때
============================================================
글이 아니라 사진/영상/지원 링크를 바꾸고 싶을 때만
EDIT_HERE.html 또는 HANYO_EDIT.html을 사용하면 돼.

한마디로:
한국어 글 = HANYO_TEXT.txt
영어 글 = HANYO_TEXT_EN.txt
사진/링크 = EDIT_HERE.html
