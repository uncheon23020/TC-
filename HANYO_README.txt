하뇨야! TC 홈페이지 수정은 이것만 보면 돼.

[절대 안 건드려도 되는 것]
- index.html
- CSS
- 자바스크립트 코드

[수정할 때]
1. HANYO_EDIT.html을 더블클릭해서 열어.
2. 기본은 '한국어'로 되어 있으니까 그대로 두면 돼.
3. 왼쪽 메뉴에서 수정하고 싶은 곳을 골라.
   - 기본 정보
   - 홈 화면
   - 동아리 소개
   - 활동 · 대회
   - 사진 · 영상 문구
   - 지원 안내
   - 이미지 · 영상
   - 링크 설정
4. 글을 그냥 입력하면 돼.
   - 줄바꿈: 엔터
   - 강조 글씨: [강조]강조할 글[/강조]
5. 다 했으면 맨 위 '수정 파일 다운로드' 눌러.
6. site-data.js 파일이 다운로드돼.
7. GitHub에서 기존 site-data.js를 그 파일 내용으로 교체하면 끝.

[중요]
- site-data.js라는 파일 이름은 바꾸지 마.
- index.html은 수정할 필요 없어.
- 한국어를 바꿔도 영어/일본어 등은 자동으로 바뀌지 않아.
- 사진은 HANYO_EDIT.html 안의 '이미지 · 영상' 메뉴에서 선택할 수 있어.

한마디로:
HANYO_EDIT.html에서 수정 -> site-data.js 다운로드 -> 기존 site-data.js 교체 -> 끝!
