2. 가장 쉬운 수정: EDIT_HERE.html

5. 언어: 한국어 / English / 日本語 / Русский / हिन्दी / Български
6. 자세한 방법은 간편_수정_안내.txt를 읽어 주세요.

기존 방식으로도 assets/images 및 assets/videos 폴더를 사용할 수 있습니다.
